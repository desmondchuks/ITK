SAVORA STATIC PROTOTYPE
========================

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract/open the folder.
2. Double-click index.html, or use VS Code Live Server.
3. Click Get Started or Log in.
4. Use the dashboard buttons to demonstrate:
   - Savings plans
   - Daily/Weekly/Monthly contributions
   - 6/9/12 month durations
   - Deposit simulation
   - Withdrawal simulation with 10% early-withdrawal fee
   - Goals
   - Contributions
   - Transactions
   - Notifications
   - Settings

This is a presentation prototype. It has no real database, authentication,
payment gateway, bank integration, or real financial transactions.
